treeline

Build, import and export ASCII folder trees. Works fully offline.

Structure

Drag the ⋮⋮ handle: drop on a row's top/bottom edge to reorder, or on its middle to move into a folder.
Double-click a name to rename; click the # text to add a description. Hover a row to add children or delete. Press Enter to confirm, Esc to cancel.

Import a folder or ASCII tree

[ ↑ ]

Drop a folder here, or choose one. Nothing is uploaded — it's read locally in your browser.

Paste an ASCII tree

Paste text you copied from the ASCII output (or from tree). Connector style, indent width and # descriptions are detected automatically. Names ending in /, or with children, become folders; other lines become files.

Create this structure on disk

Write directly into a folder

Pick a destination folder and the tree is created inside it (empty files, existing files are never overwritten). Needs a Chromium browser such as Chrome or Edge.

Download a script or zip

Works in any browser. Run the script from the folder where the tree should be created, or extract the zip there.
